# MA-Teacher (working title)

Private foundation for an English National Curriculum student/teacher companion.

This repository is intentionally a **Vite display skeleton**, not a lesson planner,
assessment engine, account system, or curriculum data import. The Captain has not
chosen a public product name or approved the detailed feature set yet.

## Current scope

- private module, separate from Mostly Armless runtime code;
- launchable local Vite surface for reviewing the documented concept;
- English National Curriculum context only;
- student and teacher views are planned as separate product roles;
- local-first handling is the default for any future classroom or learner data.

## Deliberately absent

- pupil accounts or personal data;
- curriculum content copied from third parties;
- assessment, grading, AI tutoring, cloud sync, or agent automation;
- public deployment and installer work.

The next implementation decision belongs to the Captain and should be recorded in
`docs/CONCEPT.md` before feature work starts.
