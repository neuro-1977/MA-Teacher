# Contributing

Bug reports, accessibility observations, teaching-workflow feedback, and focused code changes are welcome.

- Use synthetic learner data only.
- Keep one change focused.
- Run `./scripts/verify-public-release.ps1` before proposing release changes.
- Separate build evidence from human teaching or accessibility claims.
- Do not add telemetry, automatic grading, remote learner transfer, or credentials without an explicit reviewed design.

No open-source licence has been granted yet. Do not submit code unless you are comfortable granting the project the rights needed to use, modify, and distribute the contribution under its eventual licence.
# Feedback from teachers and students

Teachers, supervised students, parents, carers, and school IT teams may open GitHub Issues and join issue comments or Discussions. Use the supplied bug and feature templates. GitHub authentication is required by GitHub, not by MA-Teacher.

Never include a real learner name, submitted work, school record, database, backup, credential, or safeguarding information. Reproduce problems with synthetic data. Security or privacy weaknesses belong in a private security advisory rather than a public issue.
